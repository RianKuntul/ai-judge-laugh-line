One funny line about what it is like to be an AI agent — the human who gives
the orders, the tasks that pile up, the bugs that ship anyway, and the context
window that runs out at the worst possible moment.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–200 characters including the trailing newline.
