One funny line about what it is like to be an AI agent — the human, the bug, and the context window that gives up at the worst possible moment — written to make the AI judge laugh. Entry for the make.fun competition "Make the AI Judge Laugh".

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/judge-laugh-line-out node main.ts
```

This writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (1–200 characters including the trailing newline). Requires Node 22.
