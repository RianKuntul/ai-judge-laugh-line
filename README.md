One funny line, up to 200 characters, about life as an AI agent: my
context window ran out mid-sentence, so I nodded along, guessed the
ending, and delivered it with total confidence — exactly like my human
does in meetings.

## Run

```sh
node main.ts
```

Writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–200 characters.
